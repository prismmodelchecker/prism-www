# PRISM - People

PRISM was created and is still actively maintained by:

-   [Dave Parker](https://www.cs.ox.ac.uk/people/david.parker/home.html) (University of Oxford)
-   [Gethin Norman](http://www.dcs.gla.ac.uk/people/personal/gethin/) (University of Glasgow)
-   [Marta Kwiatkowska](http://www.cs.ox.ac.uk/people/marta.kwiatkowska/) (University of Oxford)

Development of the tool is currently led from [Oxford](http://www.cs.ox.ac.uk/) by [Dave Parker](https://www.cs.ox.ac.uk/people/david.parker/home.html).

The following have made a wide range of contributions to PRISM covering many different aspects of the tool (in approximately reverse chronological order):

-   [Steffen Märcker](https://cfaed.tu-dresden.de/pd-staff-Steffen) (Technische Universität Dresden)
-   [Joachim Klein](https://automata.tools/) (formerly Technische Universität Dresden)
-   [Vojtěch Forejt](http://www.cs.ox.ac.uk/people/vojtech.forejt/) (formerly University of Oxford)

We also gratefully acknowledge contributions to the PRISM code-base from (in approximately reverse chronological order):

-   Max Kurze: Language parser code improvements
-   Ludwig Pauly: Reward import/export
-   Alberto Puggelli: First version of interval DTMC/MDP code
-   Xueyi Zou: Partially observable Markov decision processes (POMDPs)
-   [Chris Novakovic](https://www.cs.bham.ac.uk/~novakovc/): Build infrastructure improvements
-   [Steffen Märcker](http://wwwtcs.inf.tu-dresden.de/~maercker/index.en.html) and [David Müller](http://inf.tu-dresden.de/index.php?node_id=3360&ln=en): Infrastructure for automata generation and explicit-state model checking
-   [Ernst Moritz Hahn](http://lcs.ios.ac.cn/en/wiki/Ernst_Moritz_HAHN): Parametric model checking, fast adaptive uniformisation + various other features
-   [Frits Dannenberg](http://www.cs.ox.ac.uk/people/frits.dannenberg/): Fast adaptive uniformisation
-   [Hongyang Qu](http://www.cs.ox.ac.uk/people/hongyang.qu/): Multi-objective model checking
-   [Mateusz Ujma](http://www.cs.ox.ac.uk/people/mateusz.ujma/): Bug fixes and GUI improvements
-   [Christian von Essen](http://www-verimag.imag.fr/~vonessen/): Symbolic/explicit-state model checking
-   [Vincent Nimal](http://www.cs.ox.ac.uk/people/vincent.nimal/): Approximate (simulation-based) model checking techniques
-   [Mark Kattenbelt](http://www.cs.ox.ac.uk/people/mark.kattenbelt/): Wide range of enhancements/additions, especially in the GUI
-   Carlos Bederian (working with [Pedro D'Argenio](http://www.cs.famaf.unc.edu.ar/~dargenio/)): LTL model checking for MDPs
-   [Gethin Norman](http://www.dcs.gla.ac.uk/people/personal/gethin/): Precomputation algorithms, abstraction
-   [Alistair John Strachan](http://devzero.co.uk/): Port to 64-bit architectures
-   [Alistair John Strachan](http://devzero.co.uk/), [Mike Arthur](http://mikearthur.co.uk/) and Zak Cohen: Integration of [JFreeChart](http://www.jfree.org/jfreechart/) into PRISM
-   Charles Harley and Sebastian Vermehren: GUI enhancements
-   [Rashid Mehmood](http://www.hud.ac.uk/ourstaff/profile/index.php?staffuid=scomrm2): Improvements to low-level data structures and numerical solution algorithms
-   [Stephen Gilmore](http://www.dcs.ed.ac.uk/home/stg/): Support for the stochastic process algebra [PEPA](http://www.dcs.ed.ac.uk/pepa/)
-   [Paolo Ballarini](https://sites.google.com/site/pballarini/) & [Kenneth Chan](http://www.csc.liv.ac.uk/~kjc): Port to Mac OS X
-   Andrew Hinton: Original versions of the GUI, Windows port and simulator
-   Joachim Meyer-Kayser: Original implementation of the "Fox-Glynn" algorithm

See also [here](/other-downloads/) for details of third-party tools/libraries included in PRISM.

Details of the people who worked on the underlying theory and techniques implemented in PRISM can be found [here](/doc/whatsinprism/).

There are also many people who have worked on case studies using PRISM. You can find details of these in the [case studies](/casestudies/) section of the site.
