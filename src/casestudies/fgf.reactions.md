# FGF signalling pathway: reactions

**1.** FGF binds to FGFR  
       FGF+FGFR ↔ FGFR:FGF (**k<sub>on</sub>**\=5e+8 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-1 s<sup>-1</sup>)  
  
**2.** Whilst FGFR:FGF exists  
       FGFR Y653 → FGFR Y653P (**k<sub>cat</sub>**\=0.1s<sup>-1</sup>)  
       FGFR Y654 → FGFR Y654P (**k<sub>cat</sub>**\=0.1s<sup>-1</sup>)  
  
**3.** When FGFR Y653P and FGFR Y654P  
       FGFR Y463 → FGFR Y463P (**k<sub>cat</sub>**\=70s<sup>-1</sup>)  
       FGFR Y583 → FGFR Y583P (**k<sub>cat</sub>**\=70s<sup>-1</sup>)  
       FGFR Y585 → FGFR Y585P (**k<sub>cat</sub>**\=70s<sup>-1</sup>)  
       FGFR Y766 → FGFR Y766P (**k<sub>cat</sub>**\=70s<sup>-1</sup>)  
  
**4.** FGFR binds FRS2  
       FGFR+ FRS2 ↔ FGFR:FRS2 (**k<sub>on</sub>**\=1e+6 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=2e-2 s<sup>-1</sup>)  
  
**5.** When FGFR Y653P, FGFR Y654P and FGFR:FRS2  
       FRS2 Y196 → FRS2 Y196P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y290 → FRS2 Y290P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y306 → FRS2 Y306P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y382 → FRS2 Y382P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y392 → FRS2 Y392P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y436 → FRS2 Y436P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
       FRS2 Y471 → FRS2 Y471P (**k<sub>cat</sub>**\=0.2s<sup>-1</sup>)  
  
**6.** Reverse when Shp2 bound to FRS2:  
       FRS2 Y196P → FRS2 Y196 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y290P → FRS2 Y290 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y306P → FRS2 Y306 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y382P → FRS2 Y382 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y436P → FRS2 Y436 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y471P → FRS2 Y471 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
       FRS2 Y392P → FRS2 Y392 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
  
**7.** FRS2 effectors bind phosphoFRS2:  
       Src+FRS2 Y196P ↔ Src:FRS2 Y2196P (**k<sub>on</sub>**\=1e+6 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=2e-2 s<sup>-1</sup>  
       Grb2+FRS2 Y306P ↔ Grb2:FRS2 Y306P (**k<sub>on</sub>**\=1e+6 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=2e-2 s<sup>-1</sup>)  
       Shp2+FRS2 Y471P ↔ Shp2:FRS2 Y471P (**k<sub>on</sub>**\=1e+6 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=2e-2 s<sup>-1</sup>)  
  
**8.** When Src:FRS2 we relocate/remove  
       Src:FRS2 → relocate out (**t<sub>1/2</sub>** = 15min)  
  
**9.** When Plc:FGFR it degrades FGFR  
       PLC+FGFR Y766 ↔ PLC:FGFR Y766 (**k<sub>on</sub>**\=1e+6 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=2e-2 s<sup>-1</sup>)  
       PLC:FGFR Y766 → degFGFR (**t<sub>1/2</sub>** = 60 min)  
  
**10.** Spry appears in time dependent manner:  
       → Spry (**t<sub>1/2</sub>** = 10min)  
  
**11.** Spry binds Src and is phosphorylated:  
       Spry+Src ↔ Spry Y55:Src (**k<sub>on</sub>**\=1e+5 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-4 s<sup>-1</sup>)  
       Spry Y55:Src → Spry Y55P:Src (**k<sub>cat</sub>**\=10s<sup>-1</sup>)  
       Spry Y55P+Src ↔ Spry Y55P:Src (**k<sub>on</sub>**\=1e+5 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-4 s<sup>-1</sup>)  
       Spry Y55P+Cbl ↔ Spry Y55P:Cbl (**k<sub>on</sub>**\=1e+5 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-4 s<sup>-1</sup>)  
       Spry Y55P+Grb2 ↔ Spry Y55P:Grb2 (**k<sub>on</sub>**\=1e+5 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-4 s<sup>-1</sup>)  
  
**12.** phosphoSpry binds Cbl which degrades/removes FRS2  
       Spry Y55P:Cbl+FRS2 ↔ FRS-Ubi (**k<sub>cat</sub>**\=8.5e-4s<sup>-1</sup>)  
       FRS2-Ubi → degFrs2 (**t<sub>1/2</sub>** = 5min)  
  
**13.** Spry is dephosphorylated by Shp2: (when Shp2 bound to FRS2)  
       Spry Y55P → Spry Y55 (**k<sub>cat</sub>**\=12s<sup>-1</sup>)  
**14.** Grb2 binds Sos  
       Grb2+Sos ↔ Grb2:Sos (**k<sub>on</sub>**\=1e+5 M<sup>-1</sup>s<sup>-1</sup>, **k<sub>off</sub>**\=1e-4 s<sup>-1</sup>)
