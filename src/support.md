# Getting help

If you have a problem or a question about PRISM, here is where to look:

1.  **Problems installing or running PRISM?**
    - See [Troubleshooting](/manual/GettingStarted/Troubleshooting/) in the manual.
2.  **Questions about modelling, properties or memory use?**
    - See the manual's [frequently asked questions](/manual/FrequentlyAskedQuestions/).
3.  **Something else about using PRISM?**
    - [Search the manual](/search/?section=Manual), or browse its [contents](/manual/).
4.  **Still stuck, or have a comment or feedback?**
    - Post a message in the [PRISM forum](https://groups.google.com/group/prismmodelchecker).
5.  **Found a bug, or want a new feature?**
    - File an [issue on GitHub](https://github.com/prismmodelchecker/prism/issues) (or post in the forum).

## Developers

If you're working on or with PRISM's source code, see the [developer resources](https://github.com/prismmodelchecker/prism/wiki)
on GitHub, or post a message in the [PRISM developers forum](https://groups.google.com/g/prismmodelchecker-dev).
