# Getting help

If you have problems [installing](/manual/InstallingPRISM/) PRISM, please read "[Common problems and questions](/manual/InstallingPRISM/CommonProblemsAndQuestions)".

For issues regarding the use of PRISM, please first look in the [FAQ](/manual/FrequentlyAskedQuestions/) and [search](/search/?section=Documentation) the [manual](/manual/).

For other questions, comments or feedback, please post a message in our [forum](https://groups.google.com/group/prismmodelchecker).

Bug reports and feature requests are always welcome. File an [issue on GitHub](https://github.com/prismmodelchecker/prism/issues) or post a message in the [forum](https://groups.google.com/group/prismmodelchecker).

If you're a developer working on or with PRISM, have a look at the [developer resources](https://github.com/prismmodelchecker/prism/wiki) or post a message to the [PRISM developers forum](https://groups.google.com/g/prismmodelchecker-dev).
