# Support

## Need help?

If you have problems [installing](/manual/InstallingPRISM/) PRISM, please read "[Common Problems And Questions](/manual/InstallingPRISM/CommonProblemsAndQuestions)".

For issues regarding the use of PRISM, please first look in the [FAQ](/manual/FrequentlyAskedQuestions/) and [search](/manual/Main/Search) the [manual](/manual/).

For other questions, comments or feedback, please post a message in our [forum](http://groups.google.com/group/prismmodelchecker).

Bug reports and feature requests are always welcome. File an [issue on GitHub](https://github.com/prismmodelchecker/prism/issues) or post a message in the [forum](http://groups.google.com/group/prismmodelchecker).

If you're a developer working on or with PRISM, have a look at the [developer resources](/wiki/Developers/Introduction) or post a message to the [PRISM developers forum](https://groups.google.com/forum/#!forum/prismmodelchecker-dev).
