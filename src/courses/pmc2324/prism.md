# Installing PRISM on your own machine

* * *

Since the use of PRISM will be required for part of the assignment, you will probably want to install a copy on your own machine. PRISM runs on Windows, Linux, Mac etc. and should be relatively straightforward to install. The main pre-requisite is that you have Oracle's [Java](http://www.oracle.com/technetwork/java/javase/downloads/index.html) installed. Distributions of PRISM are freely available from [here](/download/) and [installation instructions](/manual/InstallingPRISM/Instructions) can be found in the [PRISM manual](/manual/) (which is also distributed with the tool).

For Windows, there is self-extracting installer. For Linux/Mac, you will probably be able to use the binary versions; if not, you can also build PRISM from the source code version (as described in the [instructions](/manual/InstallingPRISM/Instructions)).

If you have any difficulties, you can check the list of [common problems and questions](/manual/InstallingPRISM/CommonProblemsAndQuestions). Otherwise, please contact [Maciej Olejnik](https://www.cs.ox.ac.uk/people/maciej.olejnik/) or [Gabriel Santos](https://www.cs.ox.ac.uk/people/gabriel.santos/).
