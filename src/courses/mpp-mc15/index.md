# [MPP](http://molecular-programming.org/) Model Checking Workshop 2015 : Probabilistic Model Checking

The site contains various resources for the Probabilistic Model Checking tutorial given at the MPP Model Checking Workshop at Caltech, 26-27th February 2015.

-   Slides for the lectures given by [Marta Kwiatkowska](http://www.cs.ox.ac.uk/people/marta.kwiatkowska/):
    
    -   [part 1](/courses/mpp-mc15/marta-mppmc-tutorial-p1.pdf) (Introduction + discrete-time Markov chains);
    -   [part 2](/courses/mpp-mc15/marta-mppmc-tutorial-p2.pdf) (Markov decision processes + strategies).
    
      
    
-   A [reference list](/lectures/references.pdf) for papers on probabilistic model checking, as cited in the lecture slides  
      
    
-   A [lab session](/courses/mpp-mc15/lab/) based on the [PRISM](/) tool.

## Background reading

-   This [tutorial paper](/bibitem/KT14/) gives an overview of probabilistic model checking for DNA programs.  
      
    
-   For a book chapter that explains how to model and analyse molecular signalling pathways in PRISM see [this](/bibitem/KNP10a/).  
      
    
-   This [tutorial paper](/bibitem/FKNP11/) is a good source of background reading on strategy synthesis.  
      
    
-   The book [Principles of of Model Checking](http://mitpress.mit.edu/books/principles-model-checking) by Christel Baier and Joost-Pieter Katoen is is a standard text on model checking.  
      
    
-   There are further tutorial papers listed [here](/publications/selected/).
