# Lab session: modelling and compositional verification of probabilistic component-based systems using PRISM

This hands-on tool session will introduce you to [PRISM](/). The software should already be installed on the PC lab machines, but if you want to use your own machine, it is easy to [download](/download/) and [install](/manual/InstallingPRISM/Instructions).

This tutorial is self-contained, but if you want information about running PRISM, the best source of information is the online [manual](/manual/).

There are two parts:

-   [Part A](/courses/sfm11connect/die/) uses a simple discrete-time Markov chain (DTMC) example - a randomised algorithm for modelling a **6-sided die** with a **fair coin**. It introduces the basics of the PRISM modelling language and the PRISM tool.  
      
    
-   [Part B](/courses/sfm11connect/power/) is based on a **dynamic power management** system, and illustrates how to build PRISM models comprising multiple interacting components. It uses both DTMC and Markov decision processes (MDPs)

If you want to learn about other aspects of PRISM, take a look at the main online [tutorial](/tutorial/).

You can also find many more interesting examples in the [case studies](/casestudies/) section of the website.
