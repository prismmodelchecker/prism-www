# [SFM-11:CONNECT](http://www.sti.uniurb.it/events/sfm11connect/) Summer-School

## Automated Verification Techniques for Probabilistic Systems

The site contains various resources for the summer-school:

-   The accompanying **tutorial chapter**, entitled "[Automated Verification Techniques for Probabilistic Systems](/bibitem/FKNP11/)", by Vojtěch Forejt, Marta Kwiatkowska, Gethin Norman and David Parker  
      
    
-   Slides for the **lectures** given by Marta Kwiatkowska and David Parker: [part 1/2](/talks/sfm11connect-part1+2.pdf) (introduction + discrete-time Markov chains); [part 3](/talks/sfm11connect-part3.pdf) (Markov decision processes); [part 4](/talks/sfm11connect-part4.pdf) (compositional probabilistic verification).  
      
    
-   A [reference list](/lectures/references.pdf) for papers on probabilistic model checking, as cited in the lecture slides  
      
    
-   A [lab session](/courses/sfm11connect/lab/) based on the [PRISM](/) tool.
