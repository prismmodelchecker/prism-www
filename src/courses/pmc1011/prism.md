# [Probabilistic Model Checking Practicals](/courses/pmc1011/)

## Installing PRISM on your own machine

* * *

Since the use of PRISM will be required for part of the assignment, you will probably want to install a copy on your own machine. PRISM runs on Windows, Linux, Mac etc. and should be relatively straightforward to install. The main pre-requisite is that you have Sun's [Java](http://java.sun.com/javase/downloads/) installed. Distributions of PRISM are freely available from [here](/download/) and [installation instructions](/manual/InstallingPRISM/Instructions) can be found in the [PRISM manual](/manual/) (which is also distributed with the tool).

For Windows, there is self-extracting installer. For Mac, you need to build PRISM from the source code (as described in the [instructions](/manual/InstallingPRISM/Instructions)). For Linux, you will probably be able to use the binary version above; if not, you can also build PRISM from the source code version.

If you have any difficulties, you can check the list of [common problems and questions](/manual/InstallingPRISM/CommonProblemsAndQuestions). Otherwise, please contact [Dave Parker](http://www.cs.ox.ac.uk/people/David.Parker/) or [Hristina Palikareva](http://www.cs.ox.ac.uk/people/Hristina.Palikareva/).
