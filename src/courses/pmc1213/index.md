# [Probabilistic Model Checking Practicals](/courses/pmc1213/)

## Michaelmas Term 2012

* * *

These practical exercises are based on the [PRISM](/) tool. This is already installed (under Linux) on the lab machines in room 379. However, you will be expected to complete some of this work outside of the lab sessions. You will also require PRISM to complete the take-home assignment at the end of the course. Therefore, you will mostly likely wish to install a copy of PRISM on your own machine. Please see [Mateusz Ujma](http://www.cs.ox.ac.uk/people/Mateusz.Ujma/) as soon as possible if you have any problems in this respect.

**Running PRISM in room 379:**  
PRISM is installed under Linux on these machines. You can run it by just typing `xprism` at the command line.

**Installing PRISM on your own machine:**  
See [here](/courses/pmc1213/prism/).
