# [KTH'15](/courses/kth15/): Probabilistic verification and synthesis

The site contains various resources for the Probabilistic Verification and Synthesis course taught at KTH Institute of Technology (August 2015).

-   Slides for the lectures given by [Marta Kwiatkowska](http://www.cs.ox.ac.uk/people/marta.kwiatkowska/):
    
    -   [part 1](/courses/kth15/marta-kth15-p1.pdf) (Introduction + PRISM);
    -   [part 2](/courses/kth15/marta-kth15-p2.pdf) (Discrete-time Markov chains);
    -   [part 3](/courses/kth15/marta-kth15-p3.pdf) (Markov decision processes + strategy synthesis);
    -   [part 4](/courses/kth15/marta-kth15-p4.pdf) (LTL verification + stochastic games);
    -   [part 5](/courses/kth15/marta-kth15-p5.pdf) (Probabilistic timed automata).
    
      
    
-   A [lab session](/courses/kth15/lab/) based on the [PRISM](/) tool.

## Background reading

-   The following papers are recommended background reading:
    
    -   for Markov chains see [this tutorial paper](/bibitem/KNP07a/);
    -   for Markov decision processes see [this tutorial paper](/bibitem/FKNP11/);
    -   for stochastic games see [this paper](/bibitem/CFK+13b/) and [this tool paper](/bibitem/CFK+13/);
    -   for probabilistic timed automata see [this tutorial paper](/bibitem/NPS13/).
    
      
    
-   The book [Principles of of Model Checking](http://mitpress.mit.edu/books/principles-model-checking) by Christel Baier and Joost-Pieter Katoen is recommended reading for the course.  
      
    
-   There are further tutorial papers listed [here](/publications/selected/).
