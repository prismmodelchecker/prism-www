-   in room 379 on Tuesdays from 10:00 to 12:00 (weeks 4, 5, 7 and 8) for Group 1;

* * *

These practical exercises are based on the [PRISM](/) tool. This is already installed on the lab machines. However, you will be expected to complete some of this work outside of the lab sessions. Therefore, you will mostly likely wish to install a copy of PRISM on your own machine. Please contact the tutors of practicals [Yannik Schnitzer](https://www.cs.ox.ac.uk/people/yannik.schnitzer/) if you have any problems in this respect.

**Running PRISM from lab machines:**  
The version of the **xprism** script, used to run the PRISM user interface, is broken on the lab machines. Run the following commands to get a fresh, working copy:

```
cd
wget https://prismmodelchecker.org/courses/pmc2526/xprism
chmod u+x xprism
```

You can then run PRISM by typing **~/xprism**.

You can also connect to a lab machine using ssh or remote desktop, e.g.: ssh -Y *user*@ecs.ox.ac.uk  
More information on remote access [here](https://wiki.cs.ox.ac.uk/support/RemoteAccess).

**Installing PRISM on your own machine:**  
See [here](/courses/pmc2526/prism/).
