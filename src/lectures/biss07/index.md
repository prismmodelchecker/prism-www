# Lectures - BISS 2007

The following are slides for a lecture course on *Probabilistic Model Checking*. This material was prepared by [Marta Kwiatkowska](http://www.cs.ox.ac.uk/people/Marta.Kwiatkowska/), [Gethin Norman](http://www.dcs.gla.ac.uk/people/personal/gethin/) and [David Parker](http://www.cs.ox.ac.uk/people/David.Parker/).

This was originally used for a 15-hour course at the [BISS 2007](http://www.cs.unibo.it/ricerca/grad/biss2007/) school in March 2007. You can also find an extended version of some of this course [here](/lectures/pmc/).

-   **Part 1: [Introduction](/lectures/biss07/01-intro.pdf)**  
    (introduction to probabilistic model checking)  
      
    
-   **Part 2: [Discrete-time Markov chains](/lectures/biss07/02-dtmcs.pdf) (DTMCs)**  
    (introduction to DTMCs and PCTL, model checking algorithms, examples)
-   **Part 3: [DTMC case studies](/lectures/biss07/03-dtmc%20case%20studies.pdf)**  
    (Bluetooth device discovery, contract signing)  
      
    
-   **Part 4: [Markov decision processes](/lectures/biss07/04-mdps.pdf) (MDPs)**  
    (introduction to MDPs and PCTL, model checking algorithms, examples)  
      
    
-   **Part 5: [Continuous-time Markov chains](/lectures/biss07/05-ctmcs.pdf) (CTMCs)**  
    (introduction to CTMCs and CSL, model checking algorithms, examples)
-   **Part 6: [CTMC case studies](/lectures/biss07/06-ctmc%20case%20studies.pdf)**  
    (dynamic power management, biological systems)  
      
    
-   **Part 7: [Probabilistic timed automata](/lectures/biss07/07-ptas.pdf) (PTAs)**  
    (introduction to PTAs and PTCTL, model checking algorithms, examples)
-   **Part 8: [PTA case studies](/lectures/biss07/08-pta%20case%20studies.pdf)**  
    (FireWire root contention, CSMA/CD)  
      
    
-   **Part 9: [The PRISM tool](/lectures/biss07/09-prism.pdf)**  
    (tool support, PRISM: functionality, resources, modelling language, properties)  
    (see also the [PRISM Tutorial](/tutorial/))
-   **Part 10: [Implementation of probabilistic model checking](/lectures/biss07/10-implementation.pdf)**  
    (implementation overview, symbolic techniques: BDDs and MTBDDs)
-   **Part 11: [Advanced topics](/lectures/biss07/11-advanced%20topics.pdf)**  
    (parallelisation, approximate verification, research areas)

All citations from the slides can be found in this list of [references](/lectures/references.pdf) and (where appropriate) the keys match those from the [PRISM bibliography](/publications/bibliography/).
