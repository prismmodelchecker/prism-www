# Lectures - ESSLLI'10

The following are slides for a lecture course on *Probabilistic Model Checking* taught by [Marta Kwiatkowska](http://www.cs.ox.ac.uk/people/Marta.Kwiatkowska/) and [Dave Parker](http://www.cs.ox.ac.uk/people/David.Parker/) at the [ESSLLI'10](http://esslli2010cph.info/) summer-school.

The course comprises five 1.5-hour lectures. You can also find [here](/lectures/pmc/) an extended version of some parts of this course (all except PTAs). The material on PTAs is an updated version of lectures from an earlier tutorial at [BISS'07](/lectures/biss07/), developed also by [Gethin Norman](http://www.dcs.gla.ac.uk/people/personal/gethin/).

The [tutorial](/tutorial/) for the probabilistic model checker [PRISM](/) provides a suitable accompanying practical course.

All citations from the slides can be found in this list of [references](/lectures/references.pdf) and (where appropriate) the keys match those from the [PRISM bibliography](/publications/bibliography/).

-   Lecture 2 - Markov decision processes (MDPs) \[[slides](/lectures/esslli10/esslli10pmc-part2.pdf)\]
-   Lecture 3 - Continuous-time Markov chains (CTMCs) \[[slides](/lectures/esslli10/esslli10pmc-part3.pdf)\]
-   Lecture 4 - Probabilistic model checking in practice \[[slides](/lectures/esslli10/esslli10pmc-part4.pdf)\]
-   Lecture 5 - Probabilistic timed automata (PTAs) \[[slides](/lectures/esslli10/esslli10pmc-part5.pdf)\]
